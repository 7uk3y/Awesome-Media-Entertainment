## Pre-Production & Storyboarding

- [ArtCraft](https://github.com/storytold/artcraft) - An intentional crafting and visual control engine built for artists, designers, and filmmakers.
- [Storyboarder](https://github.com/wonderunit/storyboarder) - Rapid storyboarding tool for directors and writers, with paper import support.

## Video Editing & Post-Production

- [EffectCraft](https://github.com/storytold/effectcraft) - Open-source motion graphics and visual effects engine built in pure Rust.
- [FilmCraft](https://github.com/storytold/filmcraft) - A clean-room reimplementation of a non-linear video editor written in pure Rust.
- [LosslessCut](https://github.com/mifi/lossless-cut) - Cross-platform GUI for lossless trimming and cutting of video, audio, and subtitle streams.
- [Natron](https://github.com/NatronGitHub/Natron) - Node-based digital compositor for visual effects and motion graphics.
- [Olive](https://github.com/olive-editor/olive) - Fast, non-linear video editing software providing node-based compositing.
- [OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO) - Interchange format and API for editorial timeline information.
- [Shotcut](https://github.com/mltframework/shotcut) - Cross-platform video editor built on the MLT multimedia framework.

## Color Management & VFX Standards

- [Blender](https://github.com/blender/blender) - Complete 3D creation suite supporting modeling, rigging, animation, simulation, and rendering.
- [MaterialX](https://github.com/AcademySoftwareFoundation/MaterialX) - Open specification and library for transferring rich material and look-development data.
- [OpenColorIO](https://github.com/AcademySoftwareFoundation/OpenColorIO) - Complete color management solution geared towards motion picture production and VFX.
- [OpenUSD](https://github.com/PixarAnimationStudios/OpenUSD) - High-performance extensible software platform for collaboratively constructing 3D animated scenes.
- [OpenVDB](https://github.com/AcademySoftwareFoundation/openvdb) - Hierarchical data structure and suite of tools for the efficient manipulation of volumetric data.

## Storage, Archiving & Production Tracking

- [AYON (OpenPype)](https://github.com/ynput/ayon-core) - Open-source pipeline for animation and VFX studios integrating with DCC applications.
- [HuskHoard](https://github.com/huskhoard/huskhoard) - Media Asset Management, Data tiering and cold storage archive engine designed for media workloads, featuring HTTP byte-range retrieval for conforms.
- [Kitsu](https://github.com/cgwire/kitsu) - Collaboration platform and production tracker for animation and visual effects studios.

## Broadcast, Streaming & Ingest

- [CasparCG Server](https://github.com/CasparCG/server) - Broadcast-grade graphics and video playout software used for 24/7 TV transmissions.
- [FFmpeg](https://github.com/FFmpeg/FFmpeg) - Complete, cross-platform solution to record, convert, and stream audio and video.
- [GStreamer](https://github.com/GStreamer/gstreamer) - Pipeline-based multimedia framework for media playback, recording, and editing.
- [OBS Studio](https://github.com/obsproject/obs-studio) - Free and open-source software for live video recording and streaming.
- [SRT (Secure Reliable Transport)](https://github.com/Haivision/srt) - Low-latency video transport protocol optimized for unpredictable public networks.

## Audio Engineering & Sound Design

- [Ardour](https://github.com/Ardour/ardour) - Digital audio workstation (DAW) for recording, editing, mixing, and mastering audio.
- [Audacity](https://github.com/audacity/audacity) - Multi-track audio editor and recorder for Windows, macOS, and Linux.
- [JUCE](https://github.com/juce-framework/JUCE) - Cross-platform C++ application framework for desktop audio applications and VST/AU plugins.
- [SoundCraft](https://github.com/storytold/soundcraft) - Open-source multi-track audio workstation and editor built in pure Rust.
