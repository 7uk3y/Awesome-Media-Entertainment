
# Contributing to Awesome Media & Entertainment

Thank you for taking the time to contribute! This list relies on community submissions to remain an accurate, high-quality directory of tools and open-source standards across film, television, VFX, broadcast, and audio engineering.

Please review the following guidelines before submitting a pull request.

---

## Submission Guidelines

To keep this list valuable to industry practitioners and engineers, we enforce strict curation standards:

1. **Open Source & Accessible:** Projects should ideally link directly to their source code repository (e.g., GitHub, GitLab) and include an OSI-approved or open-source compatible license.
2. **Active Maintenance:** Avoid submitting abandoned projects. Tools should have recent commit activity, active issue tracking, or represent a stable, foundational industry standard.
3. **Industry Relevance:** The tool must have a clear application in pre-production, production, post-production, VFX, broadcast engineering, or media processing.
4. **Objective Descriptions:** Avoid subjective marketing terms (e.g., *"the best"*, *"revolutionary"*, *"fastest"*, *"all-in-one"*). Describe what the software actually does.

---

## Formatting Rules

All entries must strictly follow this format to pass automated checks:

```markdown
- [Tool Name](https://github.com/org/repo) - Clear, concise, and objective description starting with a capital letter and ending with a period.
```

- **Alphabetical Order:** Ensure your addition is placed in **alphabetical order** within the chosen category (ignoring case).
- **One Item per Pull Request:** Please create a separate PR for each new item you wish to add. This makes review and merge conflicts much easier to handle.
- **Link Directly:** Link directly to the repository or project page. Avoid link shorteners or affiliate links.
- **Punctuation:** Descriptions must end with a full stop (`.`).

---

## How to Submit a Pull Request

1. **Fork** the repository on GitHub.
2. Create a new branch for your change:
   ```bash
   git checkout -b add-tool-name
   ```
3. Edit `README.md` to add your item in the appropriate section and correct alphabetical position.
4. Commit your change with a clear commit message:
   ```bash
   git commit -m "Add ToolName to Post-Production"
   ```
5. Push to your fork:
   ```bash
   git push origin add-tool-name
   ```
6. Open a **Pull Request** against the `main` branch. Briefly mention why this tool is valuable to the media and entertainment community in your PR description.
